🚀 Excited to share my college capstone project: **GiveLoop** — a free community giveaway & donation platform built with Next.js 16, TypeScript, Tailwind CSS, and Supabase.

GiveLoop lets people give away clothes, furniture, textbooks, and laptops they no longer need, while students and community members can browse and request them for free. No bidding, no fees — just circular economy in action.

Key features:
• Auth (email + Google OAuth) with protected routes
• Browse listings with search, filters, and sort
• Donate flow with image compression + Supabase Storage
• Request flow: donors accept/decline, contact revealed only after acceptance
• Row Level Security (RLS) on every table — built-in data privacy
• Dark mode, responsive design, SEO metadata

Tech: Next.js App Router · Supabase Auth/Postgres/Storage · Zod · React Hook Form · Lucide React

This project taught me full-stack development, database design, and security-first architecture. Would love to connect with folks working on similar community-driven tech!
